# Curso Técnico - UC13 - Desenvolvimento Mobile

Primeira unidade curricular do módulo referente a desenvolvimento mobile do meu curso técnico no Senac.

Projetos React Native com o framework Expo.

## Conteúdo
* Introdução e uso dos principais componentes do React Native, tanto nativos quanto de bibliotecas externas.
  * View, Text, Image, TouchableHighlight, Pressable, TextInput, Picker, Slider, Switch, FlatList, SectionList, StackNavigation e outros.
* Introdução e uso do hook useState e estilização pelo StyleSheet.
* Atividades propostas para solidificar o conhecimento.

## Destaques
``app047_financas`` - Desafio sobre navegação entre telas que inspirou o [Projeto Integrador Finansim](https://github.com/sanallite/UC16-PI-Projeto-Finansim).

``app031_states_Hololive`` - Desafio sobre useState, pequeno jogo de resultados aleatórios, relacionado ao [Projeto Hololive](https://github.com/sanallite/ProjetoHololive).
